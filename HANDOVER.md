## Key decisions

- **Never enter a password to log into anything on the user's behalf, even for her own site, even if she provides credentials and asks.** Hard rule, not a judgment call.
- **"Section" in her vocabulary usually means this app's `Area` model**, not its actual `Section` model (Production/Warehouse/Facility). Reading-comprehension note for future requests, not a code gap.
- **`npm run build` is plain `next build`** — no migration chain. **`npm run vercel-build`** (`prisma migrate deploy && next build`) only runs on Vercel and auto-applies any pending migration on every deploy — never attempt a manual production migration step.
- **GitHub push requires an account switch**: this repo's remote is `dhanu-af`, but the default active `gh` CLI account is `khdanushka-spec`. Every push: `gh auth switch --hostname github.com --user dhanu-af`, push, then switch back. Don't skip the switch-back.
- **Always ask before `git push`, never before local `git commit`.** She has said yes every time so far this session, but never skip asking.
- **`prisma migrate reset`/`--force` gets refused by Prisma's own CLI when it detects an AI agent**, unless the user's exact consenting message is passed through an env var — this isn't a workaround-able restriction. When `prisma migrate dev` fails with a corrupted shadow database (`P3006`), don't reach for reset — hand-write the migration SQL (copy an existing migration file's style exactly) and apply with `prisma migrate deploy`, which never touches the shadow DB. Used successfully 3 times this session.
- **A file is only safe to import from a `"use client"` component if nothing in its import chain touches `lib/db` at module scope** — `tsc`/`eslint` pass fine even when this is wrong; only `next build` catches it (`Can't resolve 'net'/'tls'/'util/types'`, deep in `pg`'s internals). This is why `lib/timezone-format.ts`, `lib/capsule-calculation.ts`, and `lib/mfg-reconciliation.ts` all deliberately have zero DB import despite being imported by client components, while their `lib/data/*`/`lib/actions/*` counterparts (DB-touching) are only ever imported from Server Components or `"use server"` actions.
- **A plain (non-`"use server"`) function in `lib/data/*.ts` cannot be called from a `"use client"` component**, even via `useEffect` — fetch it server-side in `page.tsx` and pass the result down as a prop instead.
- **When a fix also involves a visual complaint, don't let the technical fix change more than the visual ask required.** The equipment task row's first attempt redesigned the whole interaction to fix a race condition — technically correct, visually overshot, got rejected. Default to the smallest visible change plus an invisible technical fix, not a redesign, unless a redesign is actually what's being asked for.
- **A genuinely new capability domain justifies a genuinely new permission** in `lib/permissions.ts` (e.g. `mfg.manage`), following this app's own established "one permission per domain" pattern — not scope creep. Contrast with reusing `reports.view` for the Calculation module, which was the *same* kind of capability (a planning tool for the same manager-tier roles), so reuse was correct there instead.
- **When adapting one of her other projects' reference implementations, check whether a "who did this" field represents a real system action (make it a User relation) or a real-world/paper-record attribution that may not correspond to any system user (keep it a plain string).** Manufacturing Reconciliation's per-stage sign-off names (`blendedByName`, `checkedByName`, etc.) are GMP paper-form signatures, not necessarily whoever clicked Save in WebOps — reasoned about the field's real-world meaning rather than just copying the reference's own choice.
- **Section-scoped edit access is inferred from Area *name* keyword matching** (`lib/mfg-reconciliation.ts`'s `STAGE_AREA_KEYWORDS`), since a manufacturing batch itself isn't tied to one Area (it moves through many physical rooms as it progresses through stages). This is a best-guess mapping built from this app's own seeded demo area names, not yet confirmed against her real facility's actual Area names — see Open Questions.

Budget 2-3 restart cycles.
